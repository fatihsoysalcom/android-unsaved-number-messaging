# Android unsaved number messaging

This Python script demonstrates how to construct a WhatsApp message link for an unsaved number, including handling country codes and URL encoding for the message content. It generates a shareable link that can be opened in a web browser or an Android app via an Intent.

## Language

`python`

## How to Run

Run this Python script using: python main.py
Replace '905551234567' with the desired phone number including the country code.
